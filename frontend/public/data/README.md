# Vanuatu Area Council boundaries (2025 update)

`vanuatu-area-councils-2025.geojson` is a WGS84 dashboard-ready snapshot derived
from the public **AC Boundaries 2025** ArcGIS feature layer:

https://www.arcgis.com/home/item.html?id=6eb66cfdf41f4206bc34f741a98b235a

The source attributes were reduced to `ADM1_EN` and `ADM2_EN`, two unassigned
SANMA fragments were assigned using their Area Council names, duplicate South
Santo 2 geometry was dissolved, and the geometry was simplified to a 100-metre
tolerance for responsive web display while retaining every Area Council polygon.
Names were checked against the Vanuatu Department of Local Authorities and Sanma
Provincial Government Council listings. The resulting file contains 71 uniquely
named Area Council features, including Big Bay Coast, Big Bay Inland, South
Santo 1, South Santo 2, and South East Santo.

## Display topology and quiet overview map

`vanuatu-area-councils-map.geojson` is a derived display pack, generated by
`PYTHONPATH=<GIS dependencies> python scripts/build-area-council-map.py` from the
repository root (Shapely 2.2, pyproj 3.7). The original snapshot stays unchanged.
The pack retains all 71 names and source boundary segments. It includes unioned
land, shared boundary linework drawn once, and six province label points derived
from the province footprints. The optional simplified overview uses these vectors without map tiles. The
default terrain basemap and optional street/satellite imagery retain provider
attribution. The fallback land sits below imagery, so it never masks the real
coastline. Project fills are transparent; unrecorded council linework is off by
default. Since the source is simplified to 100 m, council geometry and fallback
land are hidden above zoom 11. Geographic tiles remain visible at closer zoom.

Two source self-intersections (Central Pentecost One and Northwest Santo) are
repaired only for display. The maximum absolute geodesic area change is 0.204 m².
Three tiny residual source overlap slivers (all under 37 m²) are documented in
`provenance`; no boundaries are snapped, buffered, moved or clipped to hide them.
The generator rejects missing councils, changes to existing boundary segments,
repairs of 1 m² or more, and pairwise overlaps of 100 m² or more. This is a
rendering repair, not a replacement administrative boundary survey. Administrative
areas indicate recorded project locations, not hectares of project interventions.
The embedded source SHA-256 identifies the exact reviewed input.
